# Scripts

Mỗi video là một thư mục con trong `scripts/projects/<ten-du-an>/`:

```
scripts/projects/constantinople_1453/
├── script.md      # Kịch bản đầy đủ theo cảnh
├── scenes.json    # Cảnh đã parse (tự động sinh, đừng sửa tay)
└── notes.md       # Ghi chú nghiên cứu
```

Dùng template phù hợp trong `scripts/templates/`:
- `template_biography.md` — video tiểu sử nhân vật
- `template_battle.md` — video trận chiến/sự kiện quân sự
- `template_event.md` — video sự kiện lịch sử tổng quát
